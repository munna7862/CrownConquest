## Operating Model

The team works as a coordinated sprint team.

No agent works as an isolated "feature generator".

The intended flow is:

`Plan → Implement → Integrate → Test → Review → QA → Done`

The first sprint proves the signature game mechanic before the project expands into economy and civilization systems.
