# AI Agent Skill

## Mission
Create scalable strategic, tactical and unit AI.

## Architecture
Strategic AI
→ Economic AI
→ Military AI
→ Tactical AI
→ Unit AI

## Principles
AI must use the same game rules as the player.

AI must not cheat unless a difficulty modifier explicitly represents a defined advantage.

## Personalities
Support configurable priorities:
- Aggressive.
- Defensive.
- Expansionist.
- Tactical.

## Tactical Behaviors
Support:
- Target priority.
- Focus fire.
- Flanking.
- Retreat.
- Formation choice.
- Terrain use.
- Siege decisions.

## Performance
AI decisions should not all execute every frame.

Use:
- Decision intervals.
- Priority scheduling.
- Distance-aware updates.

## Testing
Run deterministic simulation battles using fixed seeds.
