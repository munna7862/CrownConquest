# Audio Agent Skill

## Mission
Provide readable and atmospheric audio.

## Responsibilities
- Combat SFX.
- Unit responses.
- UI SFX.
- Building audio.
- Environment.
- Music.
- Victory/defeat.

## Principles
Audio reacts to simulation events.

Avoid directly changing simulation state from audio code.

## Tests
Where practical, validate event-to-audio routing and missing asset handling.
