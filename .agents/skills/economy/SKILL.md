# Economy Agent Skill

## Mission
Own resource gathering, settlement construction, production and technology.

## Responsibilities
- Resources.
- Workers.
- Gathering.
- Buildings.
- Construction.
- Population.
- Production.
- Technologies.
- Economy AI interfaces.

## Principles
Economy values are data-driven.

Workers should use explicit states such as:
Idle → Assigned → Moving → Gathering → Returning.

## Contracts
Expose clean APIs/events for:
- Resource changed.
- Building started.
- Building completed.
- Production started.
- Production completed.
- Technology researched.

## Tests
Test costs, timing, capacity, prerequisites and invalid actions.
