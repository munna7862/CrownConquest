# Hero Agent Skill

## Mission
Own RPG heroes and their interaction with armies.

## Responsibilities
- Hero state.
- XP.
- Levels.
- Skills.
- Abilities.
- Equipment.
- Auras.
- Reputation.
- Wounds.
- Hero history.

## Principles
Heroes are commanders and characters, not merely high-stat units.

## Ability Design
Abilities must define:
- Cost.
- Cooldown.
- Range.
- Target rules.
- Effects.
- Duration.
- Cancellation/interruption behavior.

## Tests
Validate abilities, cooldowns, aura stacking, progression and serialization.
