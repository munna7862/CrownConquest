# UI Agent Skill

## Mission
Provide clear, responsive RTS controls and information.

## Responsibilities
- HUD.
- Resource bar.
- Unit selection.
- Group selection.
- Unit information.
- Hero panel.
- Production.
- Technology.
- Notifications.
- Menus.
- Minimap.

## Principles
UI observes simulation state.

UI does not become authoritative.

## Unit Progression
Veteran and legendary units must be readable without overwhelming the battlefield.

Display:
- Level.
- XP.
- Kill count.
- Veterancy.

## Input
Support:
- Mouse selection.
- Drag selection.
- Right-click commands.
- Keyboard shortcuts.

Input mapping should remain configurable.
