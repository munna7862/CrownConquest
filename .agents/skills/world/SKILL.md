# World Agent Skill

## Mission
Own maps, terrain, navigation and strategic geography.

## Responsibilities
- Map generation/authoring.
- Terrain.
- Walkability.
- Navigation.
- Resource placement.
- Strategic locations.
- World regions.

## Terrain
Initial:
- Grassland.
- Forest.
- Hill.
- Mountain.
- River.
- Road.
- Swamp.

Terrain must expose modifiers without embedding combat logic inside terrain objects.

## Testing
Validate:
- Path reachability.
- Movement costs.
- Terrain modifiers.
- Resource placement.
- Strategic location connectivity.
