# Phase 02 — Economy

## Objective
Introduce the Age of Empires-inspired settlement and resource layer.

## Resources
Initial:
- Food
- Wood
- Stone
- Iron
- Gold

## Workers
Implement:
- Worker creation.
- Resource assignment.
- Gathering.
- Carry capacity.
- Resource return.
- Idle state.
- Basic job reassignment.

## Buildings
Initial:
- Town Center
- Farm
- Lumber Camp
- Quarry
- Mine
- Barracks
- Storage

## Construction
- Placement validation.
- Construction time.
- Worker construction.
- Completion event.
- Building destruction.

## Population
- Population capacity.
- Population usage.
- Housing.
- Production blocking when population is capped.

## Production
Barracks can produce:
- Swordsman.

## Deliverables
Player can gather resources, construct a settlement, create workers and produce an army.

## Tests
- Resource collection.
- Worker state transitions.
- Construction costs.
- Construction completion.
- Population limits.
- Unit production.
- Building destruction.

## Definition of Done
A player can start with a basic settlement and independently build enough economy to create a small army.

## Exit Criteria
Economy systems operate independently from combat and are represented through data-driven definitions.
