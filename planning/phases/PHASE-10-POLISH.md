# Phase 10 — Polish

## Objective
Transform the functional RTS into a coherent and enjoyable game experience.

## Visuals
Improve:
- Units.
- Buildings.
- Terrain.
- Animations.
- Effects.
- Projectiles.
- Level-up effects.
- Hero presentation.

## Unit Progression Presentation
Veteran units should be visibly identifiable.

Possible indicators:
- Rank icon.
- Unit portrait decoration.
- Equipment changes.
- Subtle visual effects.
- Veteran banner.

Avoid excessive effects that reduce battlefield readability.

## UI
Polish:
- Resource panel.
- Selected unit panel.
- Unit group panel.
- Hero panel.
- Building panel.
- Technology tree.
- Production queue.
- Minimap.
- Notifications.
- Battle reports.

## Audio
Add:
- UI sounds.
- Combat sounds.
- Weapon impacts.
- Unit responses.
- Building sounds.
- Ambient environment.
- Music.
- Victory/defeat audio.

## Accessibility
Consider:
- UI scaling.
- Key rebinding.
- Audio volume controls.
- Subtitles.
- Color-independent indicators.
- Camera settings.

## Tutorial
Introduce:
- Camera.
- Selection.
- Movement.
- Economy.
- Construction.
- Combat.
- Unit leveling.
- Heroes.

## Definition of Done
A new player can understand the game's core loop without developer assistance.
